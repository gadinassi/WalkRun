# הליכה וריצה – אפליקציית Android

קוד מקור מלא. Kotlin, Jetpack Compose, Room, OpenStreetMap (osmdroid), Credential Manager.

> **סטטוס:** הקוד לא קומפל ולא נבדק על מכשיר. נבדק רק שאין שגיאות תחביר. צפה לתיקונים קטנים בזמן הבנייה הראשונה.

## דרישות
- Android Studio עדכני, JDK 17.
- מכשיר פיזי עם GPS. אמולטור לא מתאים לבדיקת צעדים, ברומטר ו-GPS אמיתי.

## פתיחת הפרויקט
1. פתח את התיקייה `WalkRun` ב-Android Studio.
2. ב-Studio הגדר Gradle JDK = 21 (Settings → Build Tools → Gradle). Gradle 8.9 לא רץ על Java 25 שמגיע עם Studio.
   בנייה משורת הפקודה: `gradlew.bat assembleDebug` (עם `JAVA_HOME` שמצביע על JDK 21).
3. אם יש בעיה בגרסאות התלויות: Studio מציע עדכון. הגרסאות ב-`app/build.gradle.kts`.

## הגדרת כניסה עם Google (רשות)
במסך הכניסה יש כפתור "המשך בלי חשבון". הוא עובד בלי שום הגדרה. הכניסה עם Google רק מציגה את השם במסך הבית.
אין צורך ב-Firebase ואין צורך ב-`google-services.json`, כי הנתונים נשמרים מקומית.
1. Google Cloud Console → צור פרויקט.
2. הגדר OAuth consent screen (External). הוסף את החשבון שלך כ-Test user.
3. Credentials → Create OAuth client ID → **Android**:
   - Package name: `com.example.walkrun`
   - SHA-1 של מפתח ה-debug: `keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android`
4. Credentials → Create OAuth client ID → **Web application**. העתק את ה-Client ID.
5. ב-`app/build.gradle.kts` החלף את `YOUR_WEB_CLIENT_ID.apps.googleusercontent.com` בערך שהעתקת.
6. שגיאה "Developer console is not set up correctly" = ה-SHA-1 או ה-package לא תואמים ללקוח ה-Android.

## שיטות חישוב
- **קלוריות:** משוואות ACSM (חלק פעיל, כולל שיפוע עלייה) + BMR לפי Mifflin-St Jeor (משקל, גובה, גיל, מין). הערכה בלבד.
- **צעדים:** חיישן `TYPE_STEP_COUNTER`. אם אין חיישן, אין הרשאה, או החיישן לא מדווח – הערכה לפי מרחק ואורך צעד מהגובה. המסך מסמן "הערכה".
- **טיפוס:** ברומטר עם סף 1 מ'. בלי ברומטר: גובה GPS עם סף 4 מ'. גובה GPS לא מדויק.
- **הודעות קוליות:** מרחק, זמן, קצב נוכחי (ממוצע 30 השניות האחרונות), קצב ממוצע. באימון השוואה גם המרחק שנותר לפי המסלול הקודם, והפער בשניות. לפי מרחק, לפי זמן, או שניהם יחד. כששתי ההודעות נופלות בהפרש של פחות מ-30 שניות, נאמרת רק הראשונה.
- **השוואת מסלול:** לפי מרחק מצטבר: "במרחק D, בביצוע הקודם עבר זמן T". הודעה קולית כשהמצב מתחלף בין מהיר לאיטי (סבילות 5 שניות). התראת סטייה מעל 50 מ'.
- **מגמה:** קצב ממוצע מול הפעילות הקודמת. מסלול חוזר → מול הביצוע הקודם באותו מסלול. אחרת → מול הפעילות הקודמת מאותו סוג. שינוי קטן מ-2% = ללא שינוי.

## מגבלות ידועות
- אם מערכת ההפעלה הורגת את התהליך באמצע אימון, האימון אובד. אין שחזור.
- יצרנים כמו Xiaomi, Samsung, Huawei עלולים לעצור שירות רקע. יש לבטל אופטימיזציית סוללה לאפליקציה.
- שרתי האריחים של OpenStreetMap אוסרים שימוש כבד באפליקציות. לשימוש אישי זה סביר. לפרסום בחנות יש לעבור לספק אריחים אחר.
- ה-User-Agent למפה מוגדר ב-`WalkRunApp.kt`. לפני פרסום יש להוסיף לו פרטי קשר, לפי מדיניות OSM.
- במסך ההקלטה המפה עוקבת אחרי המיקום. אחרי שמזיזים אותה ביד, המעקב נעצר ל-15 שניות.
- הכניסה עם Google מזהה את המשתמש מקומית בלבד. ה-ID token לא מאומת בשרת. הנתונים לא מופרדים בין משתמשים באותו מכשיר.
- הודעות בעברית דורשות קול עברי במנוע ה-TTS (Google Speech Services). אחרת ההודעות בשפת ברירת המחדל.
- שינוי הגדרות ההודעות משפיע רק על האימון הבא.
